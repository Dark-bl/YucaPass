# YucaPass — identidad de marca

**Nombre:** YucaPass

**Lema:** Nació en Yucatán. Te lleva más allá.

**Idea:** una plataforma de pasaporte digital que conecta viajeros, hoteles, experiencias, comercios y comunidades. El nombre refleja el origen yucateco, pero permite que la plataforma crezca hacia otros destinos.

**Dirección visual conservada:** verde petróleo/azul profundo, dorado arena, superficies claras, tipografía editorial y fotografías de destinos. El rebranding cambia el nombre y el símbolo, no la estructura funcional ni el lenguaje visual aprobado.

**Emblema:** pasaporte, brújula, pirámide maya, cenote y trayectoria de viaje.

**Uso:** el proyecto incluye `yucapass-emblem.png` para paneles, `yucapass-icon-512.png` para la aplicación, `yucapass-logo.svg` como logotipo horizontal y `brand-mark.svg` como favicon.
